# Profile icons

Envelope, GitHub, LinkedIn, and mortarboard SVGs from Bootstrap Icons v1.13.1:
https://github.com/twbs/icons/tree/v1.13.1/icons

MIT license included in LICENSE. The mortarboard represents Google Scholar.
Icons are local decorative images alongside accessible text links; no CDN or icon font is required.

The tab icon, `ag-favicon-64.png`, is a 64px display copy of the supplied
`ag_icon.png`. Its document-relative URL works at both a domain root and a
GitHub Pages repository subpath. Increment its URL version in `index.html`
when replacing it to avoid reusing a cached icon.
